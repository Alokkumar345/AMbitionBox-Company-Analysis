# AMbitionBox-Company-Analysis
Exploratory Data Analysis of AmbitionBox Company Dataset using Python, Pandas, Matplotlib and Seabo

## Project Overview

This project analyzes AmbitionBox company data using Python, Pandas, Matplotlib, and Seaborn.

### Objectives

- Data Cleaning
- Missing Value Handling
- Rating Analysis
- Review Analysis
- Visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Reviews vs Ratings

## Key Insights

- Most companies have ratings above 3.5.
- Salary distribution is right-skewed.
- Review count and rating are not strongly correlated.
